Monte Carlo and Computational Statistical Physics

From Metropolis to worm algorithms, with rigorous error analysis

A comprehensive guide to Monte Carlo methods in statistical physics: Metropolis algorithm, cluster and worm algorithms, the Ising model, and practical error analysis with bootstrap, jackknife, and blocking.
Author

Ajit Kumar Sorout

Published

January 8, 2025

Modified

March 24, 2026

Monte Carlo methods are the backbone of computational statistical physics. Wherever we need to evaluate high-dimensional integrals, sample from complex probability distributions, or simulate systems near phase transitions, Monte Carlo provides a systematic and often the only practical approach. These notes cover the major algorithmic ideas, the physics they are designed to probe, and the statistical machinery needed to extract reliable results from simulation data.

What Monte Carlo Is

At its core, Monte Carlo is a method for estimating integrals (or sums) by random sampling. Suppose we want to compute: \[ \langle O \rangle = \frac{1}{Z} \sum_{\mathcal{C}} O(\mathcal{C})\, e^{-\beta E(\mathcal{C})} \] where the sum runs over all configurations \(\mathcal{C}\) of the system, \(E(\mathcal{C})\) is the energy, \(\beta = 1/k_B T\), and \(Z = \sum_{\mathcal{C}} e^{-\beta E(\mathcal{C})}\) is the partition function.

Direct summation is impossible when the number of configurations is exponentially large (for an Ising model on \(N\) sites, there are \(2^N\) configurations). Instead, we generate a sequence of configurations \(\mathcal{C}_1, \mathcal{C}_2, \ldots\) sampled from the Boltzmann distribution \(p(\mathcal{C}) = e^{-\beta E(\mathcal{C})}/Z\), and estimate: \[ \langle O \rangle \approx \frac{1}{M} \sum_{i=1}^{M} O(\mathcal{C}_i) \]

This is importance sampling: instead of sampling uniformly and weighting by the Boltzmann factor (which concentrates on an exponentially small fraction of configurations), we sample proportionally to the Boltzmann weight and estimate \(\langle O \rangle\) as a simple average.

The Metropolis Algorithm

The Metropolis-Hastings algorithm (1953) constructs a Markov chain whose stationary distribution is the Boltzmann distribution.

Detailed Balance

The key condition is detailed balance: the transition rate \(W(\mathcal{C} \to \mathcal{C}')\) satisfies: \[ p(\mathcal{C})\, W(\mathcal{C} \to \mathcal{C}') = p(\mathcal{C}')\, W(\mathcal{C}' \to \mathcal{C}) \]

This ensures that the Boltzmann distribution is a fixed point of the Markov chain.

The Algorithm

  1. Start from any configuration \(\mathcal{C}\).
  2. Propose a new configuration \(\mathcal{C}'\) (e.g., flip a single spin).
  3. Compute the energy change \(\Delta E = E(\mathcal{C}') - E(\mathcal{C})\).
  4. Accept the move with probability: \[ P_{\mathrm{accept}} = \min\left(1, e^{-\beta \Delta E}\right) \]
  5. Repeat.

The acceptance probability satisfies detailed balance when the proposal distribution is symmetric (\(g(\mathcal{C} \to \mathcal{C}') = g(\mathcal{C}' \to \mathcal{C})\)). For asymmetric proposals, one uses the Metropolis-Hastings correction.

The Ising Model as a Running Example

The 2D Ising model on a square lattice: \[ H = -J \sum_{\langle i,j \rangle} s_i s_j, \qquad s_i = \pm 1 \]

is the canonical test case for Monte Carlo algorithms. It has an exact solution (Onsager, 1944) with a second-order phase transition at \(\beta_c J = \frac{1}{2} \ln(1 + \sqrt{2}) \approx 0.4407\).

For the single-spin-flip Metropolis algorithm, the acceptance probability when flipping spin \(s_i\) is: \[ P_{\mathrm{accept}} = \min\left(1, \exp\left(-2\beta J \, s_i \sum_{j \in \mathrm{nn}(i)} s_j\right)\right) \]

Since the sum over nearest neighbors takes only a few discrete values, these probabilities can be precomputed and stored in a lookup table, making each update \(O(1)\).

import numpy as np

def metropolis_sweep(spins, beta, J=1.0):
    """One Metropolis sweep over all sites of a 2D Ising model."""
    L = spins.shape[0]
    for _ in range(L * L):
        i, j = np.random.randint(0, L, size=2)
        # Sum of nearest neighbors (periodic boundary conditions)
        nn_sum = (spins[(i+1)%L, j] + spins[(i-1)%L, j] +
                  spins[i, (j+1)%L] + spins[i, (j-1)%L])
        dE = 2 * J * spins[i, j] * nn_sum
        if dE <= 0 or np.random.random() < np.exp(-beta * dE):
            spins[i, j] *= -1
    return spins

Ergodicity and Mixing

For the Markov chain to converge to the correct distribution, it must be ergodic (any configuration can be reached from any other) and aperiodic. Single-spin-flip Metropolis satisfies both. However, the rate of convergence matters enormously: near a phase transition, the autocorrelation time \(\tau\) diverges as: \[ \tau \sim L^z \] where \(z\) is the dynamic critical exponent. For single-spin-flip dynamics on the Ising model, \(z \approx 2.17\). This is critical slowing down.

Cluster Algorithms

Cluster algorithms, introduced by Swendsen-Wang (1987) and Wolff (1989), dramatically reduce critical slowing down for systems with discrete symmetries.

The Wolff Algorithm

The idea: instead of flipping one spin at a time, build and flip an entire cluster of aligned spins.

  1. Pick a random site \(i\).
  2. Build a cluster by adding neighbors \(j\) with probability \(p_{\mathrm{add}} = 1 - e^{-2\beta J}\) if \(s_j = s_i\).
  3. Flip the entire cluster: \(s_k \to -s_k\) for all \(k\) in the cluster.

The Wolff algorithm satisfies detailed balance and has a dynamic critical exponent \(z \approx 0.25\) for the 2D Ising model — a massive improvement over Metropolis.

def wolff_step(spins, beta, J=1.0):
    """Single Wolff cluster update for 2D Ising model."""
    L = spins.shape[0]
    p_add = 1 - np.exp(-2 * beta * J)

    # Pick a random seed site
    i, j = np.random.randint(0, L, size=2)
    cluster_spin = spins[i, j]
    cluster = set()
    stack = [(i, j)]

    while stack:
        ci, cj = stack.pop()
        if (ci, cj) in cluster:
            continue
        cluster.add((ci, cj))
        # Try to add neighbors
        for di, dj in [(1,0), (-1,0), (0,1), (0,-1)]:
            ni, nj = (ci + di) % L, (cj + dj) % L
            if (ni, nj) not in cluster and spins[ni, nj] == cluster_spin:
                if np.random.random() < p_add:
                    stack.append((ni, nj))

    # Flip the cluster
    for ci, cj in cluster:
        spins[ci, cj] *= -1

    return spins

Swendsen-Wang Algorithm

Swendsen-Wang decomposes the entire lattice into clusters simultaneously using the Fortuin-Kasteleyn (FK) representation. The FK representation writes the Ising partition function as a sum over both spin and bond configurations: \[ Z = \sum_{\{s\}} \sum_{\{b\}} \prod_{\langle ij \rangle} \left[(1-p)\delta_{b_{ij},0} + p \, \delta_{s_i, s_j} \delta_{b_{ij},1}\right] \] where \(p = 1 - e^{-2\beta J}\) and \(b_{ij} \in \{0, 1\}\) is the bond variable. The algorithm alternates between updating bonds given spins and updating spins given bonds:

  1. Activate bonds: For each pair of aligned nearest neighbors (\(s_i = s_j\)), activate the bond with probability \(p\). Pairs with \(s_i \neq s_j\) are never bonded.
  2. Identify clusters: Find the connected components of activated bonds using a union-find algorithm (\(O(N)\) cost).
  3. Flip clusters: Each cluster is independently flipped (all spins reversed) with probability \(1/2\).

The key insight is that this satisfies detailed balance and the cluster size distribution is exactly the FK cluster distribution, which at \(T_c\) has a fractal structure with a power-law size distribution \(n(s) \sim s^{-\tau}\) where \(\tau = 2 + 1/\delta\) is related to the magnetic critical exponent.

def swendsen_wang_step(spins, beta, J=1.0):
    """Single Swendsen-Wang step for 2D Ising model."""
    L = spins.shape[0]
    p_bond = 1 - np.exp(-2 * beta * J)

    # Union-Find data structure
    parent = np.arange(L * L)
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]  # Path compression
            x = parent[x]
        return x
    def union(x, y):
        rx, ry = find(x), find(y)
        if rx != ry:
            parent[rx] = ry

    # Activate bonds between aligned neighbors
    for i in range(L):
        for j in range(L):
            idx = i * L + j
            # Right neighbor
            ni, nj = i, (j + 1) % L
            nidx = ni * L + nj
            if spins[i, j] == spins[ni, nj] and np.random.random() < p_bond:
                union(idx, nidx)
            # Down neighbor
            ni, nj = (i + 1) % L, j
            nidx = ni * L + nj
            if spins[i, j] == spins[ni, nj] and np.random.random() < p_bond:
                union(idx, nidx)

    # Assign random spin to each cluster
    cluster_spin = {}
    for i in range(L):
        for j in range(L):
            root = find(i * L + j)
            if root not in cluster_spin:
                cluster_spin[root] = np.random.choice([-1, 1])
            spins[i, j] = cluster_spin[root]

    return spins

When Cluster Algorithms Help

Cluster algorithms work well for models with a global \(\mathbb{Z}_2\) (or \(O(N)\)) symmetry and local interactions. They fail or become less efficient for:

  • Models with frustration (e.g., antiferromagnets on triangular lattices)
  • Models with long-range interactions (cluster identification becomes expensive)
  • Models without a simple symmetry to exploit
  • Continuous fields where the cluster definition is less natural (though generalizations exist for the \(XY\) and Heisenberg models)

The Worm Algorithm

The worm algorithm, introduced by Prokof’ev, Svistunov, and Tupitsyn (1996), takes a fundamentally different approach. Instead of working with spin configurations, it works in the path integral representation and samples both partition function configurations (closed worldlines) and Green’s function configurations (open worldlines).

Path Integral Representation

Consider a system of bosons with Hamiltonian \(H\). The partition function in imaginary time is: \[ Z = \mathrm{Tr}\, e^{-\beta H} = \sum_n \langle n | e^{-\beta H} | n \rangle \]

In the worldline representation, each boson traces out a path in spacetime \((x, \tau)\) with \(\tau \in [0, \beta]\) and periodic boundary conditions in \(\tau\):

  τ (imaginary time)
  ↑
  β ├──╮  ╭──╮      ╭──┤
    │  │  │  │      │  │
    │  │  │  ╰──────╯  │   ← worldlines
    │  │  │             │      (closed loops)
    │  ╰──╯   ╭────╮   │
    │         │    │   │
  0 ├─────────╯    ╰───┤
    └──────────────────→ x (space)
       site 1  2  3  4

  Periodic in τ: top ≡ bottom
  Hopping events: worldlines move horizontally
  On-site: worldlines at same (x,τ) interact

The weight of a configuration is determined by the kinetic energy (hopping events) and potential energy (on-site interactions).

Why Local Updates Fail

Worldlines in the path integral are closed loops (due to the trace). A local update — inserting or removing a small segment of worldline — cannot change the winding number (how many times worldlines wrap around the spatial torus). Near a superfluid transition, the winding number fluctuations diverge, and local algorithms cannot equilibrate.

The Worm

The worm algorithm introduces two special points: the head (Ira, \(\mathcal{I}\)) and tail (Masha, \(\mathcal{M}\)). The algorithm alternates between:

  • Z-sector (no worm): All worldlines are closed. Configurations contribute to the partition function.
  • G-sector (worm present): One worldline is open, with endpoints \(\mathcal{I}\) and \(\mathcal{M}\). Configurations contribute to the Green’s function \(G(x, \tau) = \langle a^\dagger(x, \tau) a(0, 0) \rangle\).
  Z-sector (closed):        G-sector (worm open):

  ╭──╮  ╭──╮                ╭──╮  ╭──╮
  │  │  │  │                │  │  │  │
  │  ╰──╯  │                │  ╰──╯  ╰── 𝓘 (head)
  │         │                │
  ╰─────────╯                ╰────── 𝓜 (tail)

  All loops closed           One open path: Ira ↔ Masha
  → measures Z               → measures G(x,τ)

The moves:

  1. Create worm: Pick a random spacetime point and open a pair (Ira, Masha) at that point.
  2. Move Ira: Advance in time, recede in time, or hop to a neighboring site.
  3. Close worm: When Ira meets Masha, annihilate them, returning to the Z-sector.

The genius of this algorithm is that the worm can wind around the spatial torus, changing the total winding number. This eliminates critical slowing down for superfluid transitions.

Measuring Observables

Superfluid density from winding numbers: \[ \rho_s = \frac{\langle W^2 \rangle}{d \beta L^{d-2}} \] where \(W\) is the total spatial winding number. This is exact (no extrapolation needed).

Green’s function: When the worm is in the G-sector, the histogram of Ira-Masha separations gives \(G(x, \tau)\) directly.

Off-diagonal long-range order (ODLRO): \[ \lim_{|x| \to \infty} G(x, 0) = n_0 > 0 \quad \text{(superfluid phase)} \]

using Statistics

function superfluid_density(windings::Vector{Int}, L::Int, beta::Float64; d::Int=2)
    W2 = mean(windings .^ 2)
    return W2 / (d * beta * L^(d - 2))
end

function binder_cumulant(windings::Vector{Int})
    W2 = mean(windings .^ 2)
    W4 = mean(windings .^ 4)
    return 1 - W4 / (3 * W2^2)
end

Long-Range Interactions: Why the Standard Worm Algorithm Breaks Down

The standard Prokof’ev-Svistunov worm algorithm achieves its efficiency through a key structural feature: after the high-temperature expansion, the amplitude integrals at each site factorize into independent single-site integrals, producing a tabulated weight function \(Q(k)\) that depends only on the local occupation number \(k_i\). This is what makes bond updates \(O(1)\).

For a model with long-range density-density interactions: \[ \mathcal{V}_{\text{LR}} = \frac{V}{2T}\sum_{i \neq j} \frac{|\psi_i|^2 |\psi_j|^2}{|\mathbf{r}_i - \mathbf{r}_j|} \]

this factorization is destroyed. The Coulomb term couples all amplitudes \(x_i = |\psi_i|\) simultaneously, so the partition function involves an \(N\)-dimensional integral over all amplitudes that cannot be reduced to a product of single-site factors. One would need a function \(Q(k_1, k_2, \ldots, k_N)\) over the full configuration space — computationally intractable even for modest \(N\).

The Mixed Representation

The solution (developed in my work with Prokof’ev and Wei) is to abandon analytical integration and instead treat field amplitudes \(\{x_i\}\) as explicit dynamical variables sampled by Monte Carlo alongside the bond currents. In this mixed representation, a configuration is specified by both bond occupations \(\{n_b^{(\pm)}\}\) and amplitudes \(\{x_i\}\), with weight:

\[ W[\{n_b\}, \{x_i\}] = \prod_b \frac{1}{T^{n_b} n_b^{(+)}! \, n_b^{(-)}!} \prod_i x_i^{p_i+1} \exp\!\left[\frac{\mu}{T}x_i^2 - \frac{U}{2T}x_i^4 - \frac{V}{T}x_i^2 \Phi_i\right] \]

where \(p_i\) is the local power from bond occupations and worm endpoints, and \(\Phi_i = \sum_{j \neq i} x_j^2/|\mathbf{r}_i - \mathbf{r}_j|\) is a Coulomb potential cache maintained incrementally.

The algorithm uses two complementary update types:

  • Worm moves change bond occupations but not amplitudes → Coulomb energy is unchanged → acceptance ratios are \(O(1)\), identical to the short-range case
  • Modulus updates change a single amplitude \(x_i\) via Metropolis → Coulomb enters as a local factor \((V/T)(x_i'^2 - x_i^2)\Phi_i\) → cache update costs \(O(N)\)

The key insight is the separation of fast and slow variables: bond/phase dynamics (fast, handled by worm moves) decouple from amplitude/density dynamics (slow, handled by modulus updates). Long-range forces only couple densities, so they are invisible to worm moves.

Cluster Algorithm and Density Invariance

A complementary approach uses the Wolff cluster algorithm. The observation is that Wolff reflections \(\psi_i \to \psi_i - 2z\,\mathrm{Re}(\psi_i z^*)\) preserve amplitudes: \(|\psi_i'|^2 = |\psi_i|^2\). Since both the Coulomb interaction and the local potential depend only on \(|\psi_i|^2\), they are exactly invariant under any cluster flip — no Metropolis acceptance step is needed. Cluster moves update phases with essentially zero critical slowing down, while separate local updates handle amplitude equilibration.

Both algorithms achieve \(\tau(L) \sim \ln L\) (dynamical exponent \(z \lesssim 0.2\)) even with \(1/r\) interactions. The cost per independent sample scales as \(C_{\text{eff}} \sim L^3 \ln L\).

Computational Considerations

For moderate system sizes (\(L \leq 16\)), the \(O(N)\) cost per modulus update is acceptable. For larger systems, Ewald summation can reduce this to \(O(N^{2/3})\) in 3D by splitting the Coulomb potential into short-range (real-space) and long-range (Fourier-space) parts. The techniques extend naturally to other slowly decaying potentials (dipolar \(1/r^3\), power-law \(1/r^\alpha\)) and to quantum lattice models in the worldline representation.

Error Analysis

Reliable error estimates are as important as the measurements themselves. Monte Carlo data is correlated in time, and ignoring these correlations leads to underestimated error bars.

The Basic Problem

If \(O_1, O_2, \ldots, O_M\) are measurements from a Markov chain, the naive estimate of the variance of the mean is: \[ \sigma_{\bar{O}}^2 \stackrel{?}{=} \frac{\mathrm{Var}(O)}{M} \]

This is wrong when the measurements are correlated. The correct expression involves the integrated autocorrelation time \(\tau_{\mathrm{int}}\): \[ \sigma_{\bar{O}}^2 = \frac{\mathrm{Var}(O)}{M} \cdot 2\tau_{\mathrm{int}} \]

The factor \(2\tau_{\mathrm{int}}\) can be large near phase transitions (for Metropolis on the Ising model, \(\tau_{\mathrm{int}}\) diverges as \(L^z\)).

Autocorrelation Function

The normalized autocorrelation function is: \[ C(t) = \frac{\langle O_i O_{i+t} \rangle - \langle O \rangle^2}{\langle O^2 \rangle - \langle O \rangle^2} \]

The integrated autocorrelation time is: \[ \tau_{\mathrm{int}} = \frac{1}{2} + \sum_{t=1}^{\infty} C(t) \]

In practice, the sum must be truncated when \(C(t)\) becomes noisy (the standard approach is to cut off at \(t \approx 6\tau_{\mathrm{int}}\), estimated self-consistently).

import numpy as np

def autocorrelation(data, max_lag=None):
    """Compute normalized autocorrelation function."""
    n = len(data)
    if max_lag is None:
        max_lag = n // 4
    mean = np.mean(data)
    var = np.var(data)
    if var == 0:
        return np.zeros(max_lag)
    C = np.zeros(max_lag)
    for t in range(max_lag):
        C[t] = np.mean((data[:n-t] - mean) * (data[t:] - mean)) / var
    return C

def integrated_autocorrelation_time(data, max_lag=None):
    """Estimate integrated autocorrelation time with automatic windowing."""
    C = autocorrelation(data, max_lag)
    tau = 0.5
    for t in range(1, len(C)):
        tau += C[t]
        # Automatic windowing: stop when t > 6*tau
        if t >= 6 * tau:
            break
    return tau

Blocking (Binning) Method

The blocking method groups consecutive measurements into blocks and computes the variance of block averages. As the block size \(B\) increases past \(\tau_{\mathrm{int}}\), the block averages become approximately independent, and the estimated error stabilizes.

The procedure:

  1. Divide \(M\) measurements into \(M/B\) blocks of size \(B\).
  2. Compute the mean of each block: \(\bar{O}_k = \frac{1}{B} \sum_{i \in \text{block } k} O_i\).
  3. Estimate the error as \(\sigma = \sqrt{\mathrm{Var}(\bar{O}_k) / (M/B)}\).
  4. Increase \(B\) and repeat. The error stabilizes when \(B \gg \tau_{\mathrm{int}}\).
def blocking_analysis(data, max_block_size=None):
    """Perform blocking analysis to estimate error."""
    n = len(data)
    if max_block_size is None:
        max_block_size = n // 10

    block_sizes = []
    errors = []

    for B in range(1, max_block_size + 1):
        n_blocks = n // B
        if n_blocks < 2:
            break
        blocks = data[:n_blocks * B].reshape(n_blocks, B).mean(axis=1)
        err = np.std(blocks) / np.sqrt(n_blocks)
        block_sizes.append(B)
        errors.append(err)

    return np.array(block_sizes), np.array(errors)

Bootstrap Method

The bootstrap constructs an empirical distribution of the estimator by resampling:

  1. From the original data \(\{O_1, \ldots, O_M\}\), draw \(M\) samples with replacement to form a bootstrap sample \(\{O_1^*, \ldots, O_M^*\}\).
  2. Compute the statistic of interest (e.g., the mean) on the bootstrap sample.
  3. Repeat \(B\) times (typically \(B = 1000\)–\(10000\)).
  4. The standard deviation of the bootstrap estimates is the error estimate.

For correlated data, use block bootstrap: resample entire blocks of size \(\geq \tau_{\mathrm{int}}\) rather than individual measurements.

def block_bootstrap(data, block_size, n_bootstrap=1000, statistic=np.mean):
    """Block bootstrap for correlated data."""
    n = len(data)
    n_blocks = n // block_size
    blocks = data[:n_blocks * block_size].reshape(n_blocks, block_size)

    estimates = np.zeros(n_bootstrap)
    for b in range(n_bootstrap):
        # Resample blocks with replacement
        idx = np.random.randint(0, n_blocks, size=n_blocks)
        resampled = blocks[idx].flatten()
        estimates[b] = statistic(resampled)

    return np.mean(estimates), np.std(estimates)

Jackknife Method

The jackknife estimates bias and variance by systematically leaving out one block at a time:

  1. Divide into \(n\) blocks.
  2. For each \(k = 1, \ldots, n\), compute the statistic \(\hat{\theta}_{-k}\) with block \(k\) removed.
  3. The jackknife error is: \[ \sigma_J = \sqrt{\frac{n-1}{n} \sum_{k=1}^{n} (\hat{\theta}_{-k} - \bar{\theta})^2} \] where \(\bar{\theta} = \frac{1}{n}\sum_k \hat{\theta}_{-k}\).

The jackknife is particularly useful for error propagation through nonlinear functions of the data (ratios, Binder cumulants, etc.), where simple error propagation formulas may not apply.

Practical Data Analysis Workflow

A typical Monte Carlo analysis involves:

  1. Thermalization: Discard the initial transient before the Markov chain has reached equilibrium. Monitor the energy or other observables and discard data until they stabilize.

  2. Autocorrelation analysis: Estimate \(\tau_{\mathrm{int}}\) for the observable of interest. This tells you the effective number of independent measurements \(M_{\mathrm{eff}} = M / (2\tau_{\mathrm{int}})\).

  3. Error estimation: Use blocking or bootstrap with block size \(B \geq 2\tau_{\mathrm{int}}\).

  4. Finite-size scaling: Run simulations at several system sizes \(L\) and temperatures \(T\) near the transition. Plot the Binder cumulant \(U_4 = 1 - \langle m^4 \rangle / (3 \langle m^2 \rangle^2)\) vs. \(T\) for different \(L\). The crossing point gives \(T_c\), and the slopes give the correlation length exponent \(\nu\).

  5. Data collapse: Rescale data as \(f(L^{1/\nu}(T - T_c))\) and check that curves for different \(L\) collapse onto a single universal function.
